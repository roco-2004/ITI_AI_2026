# Machine Learning Projects

This section contains two end-to-end supervised machine-learning notebooks with saved exploratory analysis, model comparisons, and untouched-test-set evaluations.

- [Bank Customer Churn Classification](01_Bank_Customer_Churn_Classification.ipynb) — binary classification with accuracy 0.8660 and ROC-AUC 0.8677; recall remains a limitation.
- [Bengaluru House Price Regression](02_Bengaluru_House_Price_Regression.ipynb) — regression with test R² 0.6996, RMSE 71.9076, and MAE 27.5162; it is not a production-grade model.

The excluded CSV datasets should be placed in the repository-root `datasets/` directory when rerunning the notebooks.
